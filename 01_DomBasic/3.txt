=>>> AB HAM querySelectorAll PADHTE HAI

INTRO: YAHA JO BHI PASS KROGE LIKE KOI TAG PASS KIYA TOH...
JITNE BHI TAG USE HUA HAI
HTML document MEIN WO SAARE DE DEGA...
EXAMPLE:
document.querySelectorAll('li')
OUTPUT: NodeList(3) [li, li, li]


THODA PROFESSIONAL:JO SELECTOR PASS KAROGE, USSE MATCH KARNE WALE SAB ELEMENTS DEGA.
Example:
document.querySelectorAll('li')
saare li dega.

document.querySelectorAll('.heading')
sirf class="heading" wale dega.

=>>> REMEMBER: YE JO NodeList(3) [li, li, li] ... YE POORI TARAH SE ARRAY NHI HAI...

KYOKI PURE ARRAY MEIN map() METHOD HOTA HAI... BUT YAHA
NodeList(3) [li, li, li] MEIN JAB NICHE prototype MEIN DEKHOGE TO map() METHOD NHI HOGA...
LEKIN ARRAY mein map() method HOTA HAI... CONSOLE PE CHECK KRKE DEKH LO

NODELIST EK ARRAY-LIKE OBJECT HAI, LEKIN YEH ACTUAL ARRAY NAHI HAI.
ISLIYE map(), filter(), reduce() directly AVAILABLE NHI HOTE
